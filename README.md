# Magic Town

Улаанбаатарын цаг агаар болон Монголд бүртгэгдсэн ургамлын **бодит** мэдээллийг харуулдаг Streamlit апп. Энэ хувилбар нь дата дэлгэц. Mafia тоглоомын өрөө, тоглогч, өдөр/шөнийн үе, санал хураалт, чат ороогүй.

Интерфэйс Монгол, Англи хэлээр солигдоно. Open-Meteo болон GBIF нийтийн API ашиглана. Кодонд нууц түлхүүр байхгүй, апп түлхүүр уншдаггүй.

## Юу харагддаг вэ

- **Цаг агаар:** [Open-Meteo Forecast API](https://open-meteo.com/en/docs) дээрх Улаанбаатарын цэг (47.92, 106.917), цагийн бүс `Asia/Ulaanbaatar`. Одоогийн нөхцөл болон 3 хоногийн урьдчилсан мэдээ.
- **Ургамал:** [GBIF Occurrence API](https://www.gbif.org/developer/occurrence) дээрх `country=MN`, `kingdomKey=6` (Plantae) хайлтын эхний 40 бүртгэл. GBIF дээрх нийт тоог мөн харуулна.
- Дата бүрийн **эх сурвалж**, **татсан цаг**, **хүсэлтийн хаяг** дэлгэцэнд байна.

API хариу өгөхгүй, эсвэл хүлээсэн талбар дутуу бол тэр хэсэгт алдааг Монголоор эсвэл Англиар бичнэ. Зохиомол температур, зохиомол ургамлын нэр нэмдэггүй. Нэг API унасан ч нөгөө хэсэг болон аппын цонх нээлттэй үлдэнэ.

Амжилттай таталт `.cache/` дотор 10 минут хадгалагдана. Хугацаа дууссаны дараа шинэ таталт бүтэхгүй бол сүүлийн бодит таталтыг, анх татсан цагийн хамт, анхааруулгатай харуулна. Өмнө нь нэг ч амжилттай таталт байхгүй бол алдааг л харуулна.

## Ажиллуулах

PowerShell дээр repository-ийн үндэснээс:

```powershell
cd C:\Users\mgsau\magic-town-mafia
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

`Activate.ps1` бодлогоор хаагдвал:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Хөтөч дээр гарч ирсэн хаяг руу орно. Ихэнхдээ `http://localhost:8501`.

Хажуу цэснээс хэлээ солино. **Дахин татах** товч cache-ийг хүлээлгүй шинэ хүсэлт явуулна. Автомат шинэчлэл 10 минут тутамд, амжилтгүй оролдлогын дараа дараагийн автомат оролдлого 60 секундээс өмнө гарахгүй.

## Файлууд

| Файл | Үүрэг |
| --- | --- |
| `app.py` | Streamlit дэлгэц |
| `magic_town/weather.py` | Open-Meteo таталт, шалгалт |
| `magic_town/plants.py` | GBIF таталт, шалгалт |
| `magic_town/http_json.py` | HTTPS JSON хүсэлт |
| `magic_town/cache_store.py` | Амжилттай датаг хадгалах, алдааг тусад нь хадгалах |

| `requirements.txt` | `streamlit`, `requests`, `pandas` |

`.cache/` нь локал cache тул git-д орохгүй.
